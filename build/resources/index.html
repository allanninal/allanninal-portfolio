Guides & starters

Every blueprint on this site is free to read, end to end. The paid companions — a step-by-step workflow guide and a deployable AWS CDK starter for each one — are still being written. None of them is on sale yet.

What is coming

For each of the 74 blueprints, three things are planned:

  • Workflow guide — the build, step by step, with the decisions and the dead ends, so you can put it together yourself.
  • AWS CDK starter — the same system as deployable infrastructure-as-code, so you can stand it up and adapt it.
  • Bundle — both together.

They will be sold through Gumroad when they land. Until then there is nothing to buy, and this page exists so the links on the blueprints point somewhere honest rather than at a storefront that no longer runs.

What you can do now

  • Read any series in full. Nothing is paywalled — the architecture, the cost breakdown and the engineering reference are all on the page.
  • Message me on LinkedIn if you want one of these built for your business, or if you want telling when a particular guide ships. Say which blueprint and I will come back to you when it is ready.
  • See how we could build it together if you would rather skip the guide and have the system designed for you.

Why the old shop links stopped working

These pages used to point at shop.allanninal.dev. That storefront has been retired and the domain no longer serves anything, so every one of those links was dead. They now point here instead, and each one will be swapped for its own product page as that product ships.
