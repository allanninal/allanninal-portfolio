Reference

Design system

Every ratio was computed with tools/a11y/contrast.py, not eyeballed. This page is noindex: it documents the template for whoever builds with it.

Once-only is a word, never a colour

Every slot in the run of show is marked Once only, Repeatable or Stageable after, in text. The rule down the left and the fill behind the marker repeat it. On a page about which moments are unrecoverable, encoding that in colour alone would be the worst place to do it.

The evidence sits in the slot

There is no gallery. The four photographs live inside the run-of-show entries they illustrate, because a separate grid of the same four pictures is the same evidence with the claim removed. The time axis above is decorative and aria-hidden; the ordered list is its full text equivalent.

This one took three restructures

The divergence gate rejected it at 0.127 — it was day 97 with different paint. Dropping the tables for definition lists, folding the clashes into the run and the gallery into the slots, and finally giving the day a real time axis got it to 0.314. That is a narrow pass and it is worth saying so: after ten photography templates the shared chassis is a large fraction of the fingerprint, and each fix I reach for makes the next template look more like the last one.
