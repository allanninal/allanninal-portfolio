Reference

Design system

Every ratio was computed with tools/a11y/contrast.py against all three grounds. This page is noindex: it documents the template for whoever builds with it.

The glyphs are text

Twelve characters set as live text rather than exported as an image. Select them, copy them, paste them into your own document, resize the page — which is the only test of a character that means anything, and precisely the test a PNG specimen quietly prevents. It is also why the whole page is legible at 400% zoom without a horizontal scrollbar.

Partial is a state with a column

Full, Partial, None — word, glyph, hue, as always. But the coverage table has a fourth signal the others do not: a column that names the exact missing characters wherever the state is Partial. A partial claim without specifics is a marketing claim, and it is how a font ends up shipping a cedilla where Romanian wants a comma below.

inLanguage lists only what is Full

Each family is a Product carrying its glyph count and an inLanguage list built by a strict rule: a language group appears only where the table says Full. Schema has no way to express “Romanian, except the two characters Romanian actually needs”, so putting Partial in would make the machine-readable version say exactly what the page refuses to. No offers, because nothing here is priced.

Two forms, on purpose

A trial request and a commission enquiry. Merging them gets neither — a trial is a thirty-second ask and a commission is a conversation about languages and reading sizes. This is the only template in the library with two forms and it is the thing that makes it structurally a foundry rather than a portfolio.

Rozha One — display

Fira Sans Condensed — 502 glyphs · 6 weights · 134 Vietnamese

Body is the system stack. A high-contrast Didone chosen because this page sets it at 96 px, where contrast is the whole point of the design; at 12 px it would be the wrong choice and the page never asks it to be. Neither face appears in days 1–124.
