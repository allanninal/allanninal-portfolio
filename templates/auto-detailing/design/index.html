Design system

Every ratio was computed with tools/a11y/contrast.py, not eyeballed. This page is noindex: it documents the template for whoever builds with it.

The hue was chosen by elimination

All 88 accents shipped before this were bucketed by hue in 15° steps. 225–239° was the only empty bucket in the library, so this one lands there. The first candidate was a petrol teal and it was discarded for sitting 4° from day 84 at identical lightness — which is the "same template, different colour" failure this process exists to catch.

Readings use real <meter>

min, low, high and optimum are that element's own attributes, so a value and its bounds are announced without a line of ARIA. Every panel also states its verdict as a word, so the meter is never the only route to "do not polish this".
