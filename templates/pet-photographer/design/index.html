Reference

Design system

Every ratio was computed with tools/a11y/contrast.py, not eyeballed. This page is noindex: it documents the template for whoever builds with it.

Dark, because the work is

Studio pet portraits live against black, and the previous several templates in this run were all light-ground — so this also separates the set in the gallery. Amber at hue 36° sits between hvac-service (31°, 58%) and car-wash (45°, 88%) on both axes.

Two columns, labelled in words

The spine is "what can be asked" against "what cannot". The left column takes an amber rule and the right does not, but each is headed in text — a tick-and-cross pair would put the entire meaning of the page into two glyphs.

The ratio is the argument, so it is tested

The page says the second list is longer, and that is the whole explanation for a ninety-minute session. A first draft had five in each; a test now asserts the counts in the headline match the rendered lists and that "cannot" genuinely outnumbers "can".
