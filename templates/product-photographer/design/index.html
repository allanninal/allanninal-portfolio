Design system

Every ratio was computed with tools/a11y/contrast.py, not eyeballed. This page is noindex: it documents the template for whoever builds with it.

The headline is a sum

"It is 34 exposures" is the pass counts added up, and the same number appears in the image caption and in the closing line. A test recomputes all three from the rendered rows, so editing a pass moves every figure that quotes it.

Magenta because it is a registration mark

Channel separations and registration marks are literally magenta, which is the right register for a page about compositing. The only other template in that hue bucket is remodeling-contractor; this is 29% more saturated and 11% darker. Measured, not judged.
