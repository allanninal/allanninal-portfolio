Reference

Design system

Every ratio was computed with tools/a11y/contrast.py against all three grounds. This page is noindex: it documents the template for whoever builds with it.

One set of coordinates, six drawings

The body, fins, gill and eye are five constants in the page frontmatter, and every one of the six plates draws from them. What differs is stroke weight, colour count and which parts are present — which is exactly what differs between the six real outputs. If the drawings were six independent SVGs the page would be making a claim it could not support.

The bridge in the vinyl plate is the whole point

The eye is a counter, so in the single-path version it is joined to the outside edge by a bar. Without it the shape falls out of the sheet when the cut is weeded, and a cutter will cheerfully produce that result. It is a drawing decision made for a production reason, which is the argument of the page in one detail.

The second ink is an ink

--ink-red appears in exactly one place: the risograph plate, where it is one of the two colours the drawing is genuinely separated into, offset from the teal by five units to show the misregistration the drawing is built to absorb. It is not used as a decorative accent anywhere else on the page.

Six artworks, not one with six media

Schema has artMedium on VisualArtwork, and the tempting shape is one work carrying a list of six. That would contradict the page: the medium is not a property of the drawing, it is the thing that decides what the drawing is. So the graph emits six VisualArtworks in one CreativeWorkSeries, each with only the medium it was drawn for. More verbose, and true. No image, because the drawings are SVG in the page rather than files.

Type

Halant — display

Roboto Condensed — 0.4 pt · ±1 mm · 2 px · 4 mm

Body is the system stack. Every physical constraint on the page is set in the condensed face so a measurement reads as a measurement rather than as emphasis. Neither appears in days 1–125.
