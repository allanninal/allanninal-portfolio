Reference

Design system

Every ratio was computed with tools/a11y/contrast.py against all three grounds. This page is noindex: it documents the template for whoever builds with it.

The site has no colour of its own

A true-neutral near-black, an off-white and a putty that is barely a colour. Every saturated value on this template belongs to the client identity being audited and appears only inside a specimen block or a drawn figure. A brand designer’s portfolio competing with the work inside it is a common failure and a slightly embarrassing one.

Two signals, not three

Keep, Rewrite and Drop carry no hue at all — the word, and a glyph through data-glyph. Every other template in this library adds colour as a third signal; this one cannot, because colour is reserved, so it gets by on two. Drop is set in a struck-through rule rather than in red, which is a stricter position and the one the page argues for.

One palette value deliberately fails

The client’s Flag orange sits at 3.73:1 on their Ink, which fails AA. That is not an oversight in the template — it is rule 7 of the identity, it is stated as a number rather than as advice, and Flag never carries a single character of text anywhere on this site. A test asserts it.

There is no logo file

The mark is set in type and CSS on the specimen page and inside two SVG figures. Nothing in this template is an image of a logo, which is why the CreativeWork emits no image property: pointing it at the social card would assert a file that does not exist.

Two navigations, not three

The footer navigation is gone. Every other template here has a third <nav> repeating the same four links, which is a thing that gets added because it is conventional rather than because anybody needs it.
