## Quick Generation Tips

1. **Batch generate** - Create all images in one session for consistency
2. **Maintain style** - Keep the dark background (#0a0f1a or similar) consistent
3. **Color palette** - Stick to: cyan (#06b6d4), purple (#8b5cf6), blue (#3b82f6), green (#10b981), amber (#f59e0b), red (#ef4444)
4. **Add text overlay** - After generation, add title text using Canva or similar
5. **Export** - Save as PNG, optimize for web (aim for <200KB per image)
